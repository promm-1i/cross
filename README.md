# Cross PC program

The Windows program for Cross, the Android app that lets you use a tablet on a USB cable with your Windows PC's
mouse and keyboard.

- Download: `Cross-PC.zip` under [Releases](https://github.com/promm-1i/cross/releases/latest)
- Setup guide: https://noveriq.co.kr/cross/en/ (한국어: https://noveriq.co.kr/cross/)
- Tablet app: Google Play, "Cross"

Windows 10 or Windows 11, 64-bit. Unzip and run `cross.exe`; it sits in the notification area.
If "Windows protected your PC" appears, choose More info → Run anyway.

Only the program files are published here, not the source code.
